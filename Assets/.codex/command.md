Quero refatorar os arquivos MainMenu.uxml, MainMenu.uss e GameMenu.uxml para criar uma interface moderna, limpa e consistente com a identidade visual do jogo Flip n' Flop.

### Objetivos

- Modernizar o visual dos menus sem perder a simplicidade.
- Melhorar a experiência visual e a usabilidade.
- Manter consistência entre todas as telas.
- Priorizar legibilidade, manutenção e reutilização de código.
- Seguir boas práticas do Unity UI Toolkit (UXML + USS).
- Garantir que as alterações sejam compatíveis com a estrutura atual do projeto e não introduzam bugs ou quebras de funcionalidade.
